# Deep Learning & Cybersecurity Methodology

## 1. Network Intrusion Detection Feature Representation
Network flow records describe aggregated connection statistics rather than unencrypted payload bytes. In modern enterprise environments characterized by end-to-end TLS/HTTPS encryption, deep learning models must extract behavioral indicators from packet headers, flow rates, duration, and flag transitions.

### 1.1 Dataset Schema & Harmonization
The prototype targets two primary industry-standard intrusion detection benchmarks:
1. **NSL-KDD:** Contains 41 traffic flow features comprising 4 basic categories:
   - *Basic features:* `duration`, `protocol_type`, `service`, `flag`, `src_bytes`, `dst_bytes`, `land`, `wrong_fragment`, `urgent`.
   - *Content features:* `hot`, `num_failed_logins`, `logged_in`, `num_compromised`, `root_shell`, `su_attempted`, `num_root`, etc.
   - *Time-based traffic features:* `count`, `srv_count`, `serror_rate`, `rerror_rate`, `same_srv_rate`.
   - *Host-based traffic features:* `dst_host_count`, `dst_host_srv_count`, `dst_host_same_src_port_rate`.
2. **CICIDS2017:** Generated by the Canadian Institute for Cybersecurity, representing 80 network flow statistics (packet lengths, inter-arrival times, flow byte rates, TCP window sizes).

All heterogeneous intrusion categories are mapped into **5 canonical academic classes**:
- **Benign:** Normal, non-malicious business traffic.
- **DoS (Denial of Service):** Exhaustion of target memory/bandwidth (e.g. Neptune, Smurf, Hulk, Slowloris).
- **Probe:** Reconnaissance, network topology mapping, and vulnerability scanning (e.g. PortScan, Nmap, Satan).
- **R2L (Remote to Local):** Unauthorized access trials from a remote machine (e.g. Guess_Password, FTP-Patator, Brute Force).
- **U2R (User to Root):** Privilege escalation exploiting local memory/buffer vulnerabilities to obtain root privileges (e.g. Buffer_Overflow, Rootkit).

## 2. Mathematical Formulation of the Deep Learning Architecture

### 2.1 One-Dimensional Convolutional Feature Extraction (1D-CNN)
Let $\mathbf{X} \in \mathbb{R}^{D \times 1}$ represent the normalized 118-dimensional feature vector for a network flow. The 1D convolution layer applies a bank of learnable filters $\mathbf{W}^{(l)} \in \mathbb{R}^{K \times C_{\text{in}}}$ with kernel size $K$:

$$y_i^{(l)} = \text{ReLU}\left( \sum_{j=-M}^M \mathbf{W}_j^{(l)} \mathbf{X}_{i+j} + b^{(l)} \right)$$

where $M = \lfloor K/2 \rfloor$. The 1D-CNN captures localized spatial cross-correlations between contiguous flow features (e.g. byte volume and packet rate ratios) before downsampling via MaxPooling1D:

$$p_k = \max_{j \in [0, S-1]} y_{k \cdot S + j}$$

### 2.2 Bidirectional Long Short-Term Memory (BiLSTM)
To capture bidirectional feature progression and high-order inter-attribute dependencies, a Bidirectional LSTM layer processes the sequence representations:

For forward direction $\overrightarrow{\mathbf{h}}_t$ and backward direction $\overleftarrow{\mathbf{h}}_t$:
$$\mathbf{f}_t = \sigma(\mathbf{W}_f \mathbf{x}_t + \mathbf{U}_f \mathbf{h}_{t-1} + \mathbf{b}_f)$$
$$\mathbf{i}_t = \sigma(\mathbf{W}_i \mathbf{x}_t + \mathbf{U}_i \mathbf{h}_{t-1} + \mathbf{b}_i)$$
$$\widetilde{\mathbf{C}}_t = \tanh(\mathbf{W}_c \mathbf{x}_t + \mathbf{U}_c \mathbf{h}_{t-1} + \mathbf{b}_c)$$
$$\mathbf{C}_t = \mathbf{f}_t \odot \mathbf{C}_{t-1} + \mathbf{i}_t \odot \widetilde{\mathbf{C}}_t$$
$$\mathbf{o}_t = \sigma(\mathbf{W}_o \mathbf{x}_t + \mathbf{U}_o \mathbf{h}_{t-1} + \mathbf{b}_o)$$
$$\mathbf{h}_t = \mathbf{o}_t \odot \tanh(\mathbf{C}_t)$$

The composite representation concatenates both passes:
$$\mathbf{H}_t = [ \overrightarrow{\mathbf{h}}_t \,\|\, \overleftarrow{\mathbf{h}}_t ]$$

### 2.3 Multi-Head Scaled Dot-Product Attention Mechanism
Anomalous network signatures often reside within a small subset of flow features (e.g. abnormal `dst_host_srv_diff_host_rate` combined with high `serror_rate`). To dynamically weight the most salient feature states, a Multi-Head Attention layer is integrated:

$$\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\left( \frac{\mathbf{Q}\mathbf{K}^T}{\sqrt{d_k}} \right) \mathbf{V}$$

For $H=4$ heads:
$$\text{MultiHead}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{Concat}(\text{head}_1, \dots, \text{head}_H)\mathbf{W}^O$$
$$\text{head}_i = \text{Attention}(\mathbf{Q}\mathbf{W}_i^Q, \mathbf{K}\mathbf{W}_i^K, \mathbf{V}\mathbf{W}_i^V)$$

The output passes through a residual skip connection and layer normalization:
$$\mathbf{Z} = \text{LayerNorm}(\mathbf{H} + \text{MultiHead}(\mathbf{H}, \mathbf{H}, \mathbf{H}))$$

### 2.4 Multiclass Softmax Classification & Weighted Loss Function
Global Average Pooling pools temporal dimensions into a latent vector $\mathbf{z} \in \mathbb{R}^{d}$, fed into a dense layer with softmax activation:

$$P(y = c \mid \mathbf{x}) = \frac{e^{z_c}}{\sum_{j=1}^C e^{z_j}}$$

To counter extreme class imbalance (where Benign and DoS represent over 80% of records while U2R represents less than 1%), training optimizes **Weighted Cross-Entropy Loss**:

$$\mathcal{L} = - \sum_{c=1}^C w_c \cdot \mathbb{I}(y = c) \cdot \log P(y = c \mid \mathbf{x})$$

where class weights $w_c$ are calculated inversely to class frequency $N_c$:
$$w_c = \frac{N_{\text{total}}}{C \cdot N_c}$$

## 3. Leakage Prevention Protocol
1. **Separation of Preprocessing Statistics:**
   - The mean $\mu_{\text{train}}$ and variance $\sigma^2_{\text{train}}$ used in `StandardScaler` are computed **solely on the training partition**.
   - The vocabulary of categorical values in `OneHotEncoder` is established on the training partition; unseen testing categories are safely encoded as zeros (`handle_unknown='ignore'`).
2. **Exclusion of Non-Feature Artifacts:**
   - The NSL-KDD `difficulty_level` attribute (indicating how many learning models previously misclassified the sample) is explicitly stripped to prevent target leakage.
